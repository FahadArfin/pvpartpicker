# Specification research: batch twelve

Batch twelve investigated 240 previously untouched families, covering 240 exact listings, and ten additional kit families. Independent reviewers approved 193 source records. The fixed pre-import comparison proves 808 new verified technical fields across 166 identities and 54 additional panel STC/NOCT cells. The nominal-voltage supplement keeps the complete published 48V/44V startup text and separately exposes the explicit 48V nominal system value; product scalar properties and conditional-limit parsing are unchanged.

The batch resolves 542 comparison gaps and completes eight kit listings. The fixed current catalog has 8,591 listings; 7,285 still have 40,113 missing comparison fields across 4,441 families. Its fresh pre-import baseline contained 40,655 gaps, one more than the previous report because an existing MRCOOL listing no longer supplied a listed cable length. This catalog/report drift is not credited as research progress.

Source review rejected title-only battery-cell/SOK capacity upgrades, inconsistent Celsius/Fahrenheit endpoints, conflicting PV voltage limits, per-port PV power presented as whole-system power, and an unsupported continuous-charge qualifier. The corrected storage packet adds eight exact PowMr prose-backed chemistry/current fields that the initial extraction missed. Conditions, per-unit scope, original capture dates and source kinds remain explicit. Classification holds remain unresolved, including a Rich Solar kit whose exact contents are known but whose raw role prevents safe import. BigBattery K0224 remains held because its title says two batteries while the exact contents block says one. No held value is promoted.

Preservation checks retain all 4,060 prior indexed identities, 26,767 stronger technical field objects, 7,117 source objects and 2,306 existing panel cells/provenance. One independently reviewed correction replaces an invalid prior Dimensions value of 53.35 lbs with exact per-module dimensions from the matching SGN-450-BDG5 datasheet. The complete prior object, source hashes and bounded correction audit are retained in specification-batch-twelve-dimensions-correction.json. Other changes are reviewed upgrades of listing-only attributes. Source packets and per-family attempts remain in ignored `output/specification-research/`; none of the remaining families is marked exhausted merely because a parser or page omitted a field.

The hosted price workflow remains enabled and its schedule/configuration, current offer amounts and observation history are unchanged by this patch. A standard hosted check on main completed successfully, reporting zero available jobs; this does not represent a new price observation. The action polls every 15 minutes and retailers use their own source schedules. Historical backfill remains paused.

This batch is part of the continuing exhaustive task. Final tests, typecheck, production Worker build, independent branch review, required CI and exact Sites publication are release gates. Live verification must compare the published values/provenance and deployment assets before reporting this batch as published. The next continuation investigates remaining pending and held families without another approval request.
