# Specification research: batch thirteen

Batch thirteen investigated 254 families across all twelve categories: 240 assigned generation/storage/balance families, nine remaining kit families and five shutdown/transmitter families. Independent reviewers approved 172 exact source records. The fixed 8,591-listing comparison proves 826 new verified technical fields across 167 identities, resolving 501 comparison gaps and completing four listings. There are no new panel STC/NOCT cells in this batch.

Review held 79 panel electrical rows whose source did not publish STC conditions, rather than letting the importer invent test conditions. It also removed title-only busbar ratings, unsupported nominal voltage, wrong-model Orion values, and conflicting battery dimensions. Corrected records retain conditional AC power, exact dimensional tolerances and original manual provenance. Four approximate weights remain unparsed and are excluded from the delivered additions. The exact SGN-450-BDG5 per-module weight is published with its manufacturer source. Legacy notes and conflicting values remain explicitly queued.

Preservation checks retain all 4,198 prior indexed identities, 27,576 stronger field objects, 7,390 source objects and 2,360 panel cells/provenance. Independent reviewers checked source hashes, relevant full technical tables and visual PDF model columns, exact raw identities, negative guards and held-value nonleakage. This does not claim review of every uncited page or exhaustion of any partially investigated family.

Hosted price collection remains enabled. A standard hosted run completed five retailer jobs; the live catalog has 1,133 offer timestamps after that run began. It added two catalog listings and changed four legacy EG4 source identities. The strict evidence guards withhold mismatched historical specification bindings; they are not automatically rebound from a shared canonical ID. A separate source-identity audit is in progress, because model, voltage, revision and package identity must be established before reuse. Price amounts, observation history, source schedules and runtime code are unchanged by this data patch.

The fixed batch leaves 7,281 listings with 39,612 missing comparison fields. The current 8,593-listing catalog has 7,283 listings with 39,652 missing fields; the additional 40 gaps from source-identity/catalog drift are reported separately and are not credited as research progress. The queue retains all attempts, source conflicts and access refusals, and continues without another approval request.

Release gates are full tests, typecheck, exact production build, fresh independent whole-branch review, required CI, terminal Sites deployment success, live checks of newly matched values/provenance and assets, and explicit verification that the four identity holds remain guarded. This batch does not complete the exhaustive goal.
