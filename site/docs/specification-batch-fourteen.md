# Specification research: batch fourteen

Independent source review approved 165 records from 189 assigned families and six supplemental attempts across the catalog categories. Full source inspection covered 194 families; an APsmart source refusal is recorded as an uninspected attempt, not completed research. The fixed and current catalog both contain 8,593 listings. This batch adds 748 verified technical fields across 151 identities and 30 explicitly sourced panel STC cells, resolving 320 comparison gaps. There remain 7,282 incomplete listings with 39,332 missing comparison fields in 4,438 source families. Partial investigations and their unresolved reasons remain queued.

Review preserved all 4,359 prior indexed identities, 28,402 stronger field objects, 7,640 source objects, 2,360 prior panel cells and their actual flat source references, and the first 3,890 approved registry records. The current index contains 4,502 identities. Review held conflicting battery dimensions, unclear cell inclusion, old Shopify variants without a supported new manufacturer binding, wrong-model Jackery text, and nominal DC ratings that conflict with existing AC-derived anchors. Emporia accuracy applies specifically to standard rigid Gen 3 mains CTs, excludes flexible coils, and does not promise the same accuracy for every branch load. Tigo communication fields are scoped to PLC without importing conflicting power/current ratings.

The source audit found acquisition process limitations. Storage helpers overlapped; the minimum observed global start gap was 0.352161 seconds. Original retained tool responses were recovered and independently verified for the affected successful evidence. Generation used 2,300 ms per-origin pacing, but ten cross-origin starts were faster, with a 319.305 ms global minimum. One overwritten failed robots response lacks its original retained body. Failed captures are excluded from approved candidate evidence. These reviews establish the approved source facts and retained bytes, not perfect global pacing or preservation of every failed response. Future acquisition requires one collector process, no overlapping requests, and at least 2,300 ms between all source starts, respecting longer source requirements and persisted refusals.

Kit details now render exact identity-guarded, sourced package contents and their manual instead of reporting that a component list is unpublished. Both specification and bundle presentations use a package-field whitelist, preserve manufacturer provenance, and reject stale name/source/category/anchor bindings. Inherited panel, inverter or battery scalar ratings are excluded as whole-kit ratings. Five actual rendered-component tests cover contents, stale identity, missing identity, scalar nonleakage and the bundle text. No decorative layout or theme changes are included.

Eleven proposed category corrections have independent source support and seven remain held. None of those role changes is implemented in this release. Four existing legacy EG4 source/model/package collisions remain guarded; evidence is not rebound merely because a canonical ID is shared. Those repairs and nominal DC/AC parsing are separate follow-up work.

Hosted price collection remains enabled and unchanged. Scheduled run 38297483499 completed successfully; the observed catalog contains 15 Inverters R Us offer timestamps after its start. This single run does not establish that every retailer ran in that interval. Historical backfill remains intentionally paused. No price amounts, observation histories, source schedules or workflow files are changed by this batch.

Release gates are full tests, typecheck, a production Worker build, fresh independent whole-branch review, required CI, terminal Sites deployment success, live value/source/asset checks, and desktop/mobile checks of kit contents in both themes. The exhaustive research goal remains active after this release.
